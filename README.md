# Maize Defense

Single-file PWA puzzle game. Place limited fences so the pig's shortest route to the corn crib is as long as possible. 21 fields plus a daily field (mud = 2x steps, ice = no turning, two-pig fields).

- Live (private artifact): https://claude.ai/artifact/NBD5BViMUi4cm346zeZecV (version 6)
- Source: index.html (game, one file), manifest.webmanifest. Icons icon-192.png and icon-512.png are only on the artifact, not in this repo.
- Ice junction fields (16, 19, 20, 21): one ice square with rocks on its four corners; seeds pinned so the best layout crosses it twice.
- Scoring: more steps wins. Daily field only: faster time breaks ties; clock is wall-clock and cannot be paused.
